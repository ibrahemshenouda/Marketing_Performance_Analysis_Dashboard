# Marketing Performance Analysis Dashboard 📊

A Power BI project designed to analyze marketing and product performance through interactive dashboards and data visualizations.

## 🛠️ Tools Used
- Power BI
- Power Query
- DAX

## ⚙️ Project Workflow
1. Data cleaning and transformation using Power Query.
2. Creating DAX measures for performance analysis.
3. Building interactive dashboards.
4. Visualizing marketing and product performance.

## 📁 Project Files
- `Performance_Analysis.pbix` — Power BI dashboard.
- `marketing_and_product_performance.csv` — Dataset used for analysis.
- `Video.mp4` — Project demonstration.
